# Publish this research page in Google Sites

This package contains a standalone HTML preview (`index.html`), your optimized photo (`assets/portrait.jpg`), your CV (`assets/Jun_Huang_CV.pdf`), and a plain-text version for **native Google Sites** (`GOOGLE_SITES_COPY.txt`).

## Recommended: build in native Google Sites (easy to update)

1. Sign in at https://sites.google.com/new and start a **Blank** site.
2. Name it **Jun Huang | ML Systems Research**. Choose a simple light theme, plain white background, and a compact header.
3. Copy the content from `GOOGLE_SITES_COPY.txt` into text boxes. Format the page title as a title, and ABOUT, SELECTED RESEARCH & PUBLICATIONS, RESEARCH & INDUSTRY EXPERIENCE, EDUCATION, and CONTACT as headings.
4. Use **Insert → Images** to upload `assets/portrait.jpg`. Keep it fairly small, beside or below the introduction. Use the alt text **Portrait of Jun Huang**.
5. Add publication links using the two real URLs in the copy file. **LOCA has no public paper URL in the supplied resume**, so leave that item unlinked.
6. Upload `assets/Jun_Huang_CV.pdf` to Google Drive and set its view permission so intended visitors can access it. Link **CV (PDF)** to that file. Test from a private/incognito browser window.
7. Use **Preview** to verify the layout on desktop and mobile. At the top right click **Publish**, choose an available web address, and verify the site's published-view audience is public (if that is your intention). Copy the published URL for applications and interviews.

## Alternate: standalone HTML

Open `index.html` locally to preview. For web hosting, upload `index.html` and the `assets` folder together to a static site host. Google Sites does not offer a one-click import of this entire HTML project as native editable sections. For Google Sites, the text-copy workflow above is simplest.

Google Sites can also embed HTML/CSS via **Insert → Embed → Embed code**, but that behaves differently from native text blocks and the local image/CV paths in this preview will not work in such an embed without public hosting. This package intentionally favors easy native editing.

## Notes

- The public site deliberately omits the phone number on the resume.
- The research descriptions are summaries based on the supplied CV. No additional or unverifiable publication links were added.
- This package is *prepared for publication*; it has not been published to your Google account.
